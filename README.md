# ReFil 3D

Sitio web del proyecto ReFil: reciclaje de botellas PET y filamento para impresión 3D.

## Páginas

- `index.html`: proyecto, proceso, sobre nosotros e impacto.
- `vender.html`: calculadora de aporte de botellas y puntos propuestos en Cochabamba.
- `comprar.html`: página de filamento, a Bs 144 por rollo.

## Abrir en VS Code

Abre `index.html` con Live Server o usa cualquier servidor estático desde la carpeta del proyecto. Por ejemplo, con Node.js:

```powershell
npx serve .
```

Después abre la dirección local que indique el servidor.
